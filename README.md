
# Olist 데이터 분석 및 AI 실습

## 1. 프로젝트 소개
브라질 이커머스 Olist의 주문 및 고객 데이터를 활용하여
데이터 분석, 머신러닝, RAG 챗봇을 학습하는 프로젝트입니다.

## 2. 학습 목표
- Python과 Pandas를 활용한 데이터 분석
- 데이터 전처리 및 시각화
- 머신러닝 모델 학습
- 학습한 모델 활용
- RAG 기반 질의응답 챗봇 구현

## 3. 프로젝트 구조

- `data/` : 분석에 사용하는 데이터
- `rag/` : RAG 챗봇 참고 자료
- `STEP1_Model_Training/` : 데이터 분석 및 모델 학습
- `STEP2_Model_Serving/` : 학습 모델 활용
- `STEP3_Local_Deploy/` : 로컬 배포 준비
- `STEP4_RAG_Chatbot/` : RAG 챗봇 실습

## 4. 개발 환경
- Windows 11
- Python 3.10
- VS Code
- Google Colab
- Jupyter Notebook

## 5. 학습 진행 과정
1. Olist 데이터 이해
2. 데이터 정제 및 병합
3. 탐색적 데이터 분석(EDA)
4. 머신러닝 모델 학습
5. 학습 모델 활용
6. RAG 챗봇 구현

## 6. 참고 자료
- Olist Brazilian E-Commerce Dataset (Kaggle)
- MBC AI 기반 데이터 저널리스트 양성 과정
- GitHub: journal-izm/Olist-Data-Analysis
